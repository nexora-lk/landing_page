Core Apple Design Philosophy — Jony Ive era
The 5 unbreakable laws
01

Clarity over cleverness

Every element must have one job. If you can remove it and the page still works — remove it. The best UI is the one users never notice.

02

Hierarchy does the talking

One thing must be the most important. One. Everything else supports it. Size, weight, and color exist only to guide the eye — not decorate the page.

03

Whitespace is not empty space

Whitespace is breathing room. It creates focus, luxury, and calm. Crowded = anxiety. Spacious = trust. Apple uses 2× the whitespace you think you need.

04

One action per screen

Never ask users to decide between many things. Guide them to one next step. Choice paralysis kills conversions and creates confusion for non-technical users.

05

Consistency is trust

Same button style. Same spacing. Same tone of language. When things behave as expected, users feel safe. Every inconsistency is a micro-confusion.

✓ Do

Use 2 font sizes max per component. Let weight (300/400/500) create the hierarchy, not 8 different sizes.

✗ Don't

Never use more than 3 font sizes on a single page. Never go below 14px for body. Never mix 3+ font families.

Color — the Apple way

Apple uses neutral backgrounds with a single accent color. The accent does all the emotional work.

✓ Do

60% neutral background · 30% text & structure · 10% accent color for CTAs only.

✗ Don't

Don't use color to decorate. Don't have 5+ accent colors. Don't use dark backgrounds unless dark mode is intentional.

Spacing — the secret weapon

Base unit = 8px. Everything is a multiple: 8, 16, 24, 32, 48, 64. Never use random values like 11px or 23px.

8px — inline gap, icon padding
16px — component internal padding
32px — between sections
64px — major section breaks
96px+ — hero sections, top padding
The complete checklist
  • ✓
    Max line width 65–75 characters per line (600–680px). Wider = unreadable.
  • ✓
    Every clickable element is at least 44×44px (Apple's minimum tap target).
  • ✓
    Your primary CTA button has only one per section. It must be obvious.
  • ✓
    Text contrast ratio 4.5:1 minimum. Use a contrast checker before shipping.
  • ✓
    Mobile-first. If it doesn't work on a phone, it doesn't work.
  • ✓
    Images never compete with text. Mute the photo, strengthen the words.
  • ✓
    Navigation has 5 items or fewer. More = confusion.
  • ✗
    No more than 3 fonts on a page. No decorative fonts for body text.
  • ✗
    No heavy drop shadows. Use subtle 1px borders instead.
  • ✗
    No gradients unless they serve a purpose. Flat is timeless.
  • ✗
    No text on busy images without an overlay. Readability first, always.
  • ✗
    Never auto-play video or audio. Earn the user's attention, never steal it.
The 3-second rule
3"

What is this?

User must understand your site's purpose in 3 seconds or they leave.

1

Action to take

One primary CTA visible above the fold. One job per page. Always.

0

Confusion points

Zero moments of "what do I do next?" That is the goal of great UX.

Buttons — the most important component
✓ Hierarchy

One filled (primary). One outlined (secondary). One text link. Never two filled buttons side by side.

✗ Common mistakes

Rounded pill buttons for primary CTAs. Square buttons feel dated. Always use border-radius 980px for main actions.
